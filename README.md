# Ore Belt

**v1.2.0** · [플레이](https://jflakeee.github.io/The_Space_Game/) · [변경 로그](CHANGELOG.md) · ![test](https://github.com/jflakeee/The_Space_Game/actions/workflows/test.yml/badge.svg)

소행성 채굴 + 타워 디펜스 웹게임. 플래시 게임 The Space Game의 규칙에서 영감을 받은 클린룸 구현으로,
원작의 코드, 그래픽, 사운드는 사용하지 않았습니다.

- 임무 25개(캠페인·확장·유리 군단 편) + 무한 모드 + 일일 도전
- 건물 10종, 적 2개 진영 16종(보스 3종), 환경 위험 3종
- 맵 에디터·리플레이 링크 공유, 업적·통계, 도감, 스토리
- 한국어/English, PWA(설치·오프라인), 모바일 터치, 접근성 옵션
- 빌드 도구·외부 의존성 없음

## 배포
저장소 전체를 GitHub Pages로 배포합니다(Settings → Pages → Source: `main` / `/ (root)`). 빌드 단계는 없습니다.
로컬: `python -m http.server` 후 http://localhost:8000

## 캠페인
확장 임무 11–20: 격파 목표(보급선 차단, 섬멸전), 보스 격파 목표(요새 공략, 쌍둥이 요새), 제약·변형 규칙(레이저 금지, 이온 성운, 적 속도 +35%, 적 체력 +20%, 소행성 10개), 최종 20웨이브(벨트의 끝). 10번 임무를 완료하면 순서대로 열립니다.
맵 4종: 산개(scatter), 고리(ring, 기지를 둘러싼 소행성대), 군집(cluster, 먼 광맥 덩어리), 교차(lanes, X자 소행성 띠가 전력망을 가름). 무한 모드는 무작위.
임무 25개 + 무한 모드. 임무를 깨면 다음 임무가 열리고, 무한 모드는 5번 임무 완료 후 열립니다.
별점은 잃은 건물 수 기준(3개 이하 ★3, 10개 이하 ★2). 진행 상황은 브라우저에 저장됩니다.
건물은 임무 1–4에 걸쳐 단계적으로 해금됩니다.

## 두 번째 진영: 유리 군단
수정 드론 해적단. 붉은 무리와 다른 방식으로 싸웁니다.

| 적 | 특징 |
|---|---|
| 분광 드론 | 약하지만 대량으로 몰려옴 (아크 코일 특효) |
| 수확선 | 채굴기를 노려 광석을 훔침. 격파하면 훔친 광석 회수 |
| 수선함 | 주변 아군을 계속 치료 |
| 위상선 | 4초마다 앞으로 순간이동해 방어선을 건너뜀 |
| 수확 모체 | 보스. 드론을 계속 낳고, 근처에 건물이 있으면 전력을 흡수 |

임무 21–25(유리 군단 편), 무한 모드 10웨이브부터 두 진영 혼합, 일일 도전·맵 에디터에서 진영 선택 가능.

## 스토리
광업 조합의 신입 계약자가 해적단 "붉은 무리"로부터 소행성대를 지키는 이야기. 20개 임무마다 관제관 세라의 브리핑(일부는 감청된 해적 통신 포함)과 완료 후 한마디가 있습니다. 설정에서 브리핑을 끌 수 있습니다.

## 환경 위험
- **유성우**: 붉은 점선 원으로 예고된 지점에 약 3초 뒤 충돌(피해 70, 건물·적 모두). 16·20번 임무, 무한 모드 8웨이브부터
- **이온 성운**: 내부 태양광 ×0.4, 내부 적 속도 ×0.7. 13·20번 임무
- **태양 플레어**: 12초간 태양광 ×2, 적 속도 ×1.2, 화면이 주황빛. 15번 임무
일일 도전 변형 규칙과 맵 에디터 규칙에도 포함되며, 도감에서 설명을 볼 수 있습니다.

## 리플레이
시뮬레이션이 고정 틱(1/40초)과 시드 난수로 돌아가므로, 리플레이는 "임무 + 시드 + 설정 + 시간별 플레이어 행동"만 저장합니다(보통 1KB 안팎). 최근 5판 자동 저장, 1–8배속 관전, 링크 공유(`#replay=...`). 같은 버전의 게임에서만 정확히 재생됩니다. 리플레이 시청은 통계·업적·기록에 반영되지 않습니다.

## 맵 에디터
소행성을 탭해서 추가(S/M/L)·삭제하거나 무작위 패턴(산개/고리/군집/교차)으로 생성. 규칙: 목표(웨이브/광석/격파/무한), 시작 광석, 적 강도, 변형 4종. 바로 테스트 플레이 가능.
**공유**: 맵 전체가 URL에 담깁니다(`#map=...`, 약 130자, 서버 불필요). 링크를 연 사람은 메뉴 맨 위에서 바로 플레이하거나 편집할 수 있습니다.

## 업적·통계
업적 16종(누적 채굴·격파, 보스 격파, 무손실 방어, 연쇄 반응, 어려움 클리어 등)과 누적 통계(플레이 수, 승리, 시간, 채굴, 격파, 건설 등). 임무 결과 화면에 새 업적 표시.

## 편의 기능
- 접근성: 색상 모드(기본 / 적록 색각 보정 / 고대비), 섬광 효과 줄이기(동작 줄이기 환경에선 기본), 0.5× 속도, 알림의 스크린리더 낭독(aria-live)
- 모바일 조작: 건설 모드에서도 한 손가락 드래그로 화면 이동, 위치를 탭하면 미리보기와 ✓/✕ 버튼, 미리보기를 끌어 위치 조정, 넓어진 건물 터치 판정, 하단 시트형 정보 패널(닫기 버튼), "기지로" 버튼, 진동 피드백(지원 기기)
- 건설 방식 설정: 시간 소요(기본) / 즉시(원작식)
- 설정: 언어, 난이도, 소리, 화면 흔들림(모션 줄이기 환경에선 기본 끔), UI 크기, 체력바 항상 표시, 진행 초기화
- 키보드 카메라: WASD/방향키 이동, +/- 확대
- 도감: 건물·적 아이콘, 수치, 상대법 (메뉴/일시정지에서). 새 적이 처음 나오면 특징 안내
- 자동 저장(10초마다, 일시정지, 탭 전환, 페이지 닫을 때) → 임무 선택 화면에서 이어하기
- 일시정지 메뉴: 계속 / 다시 시작 / 임무 선택 (Space, Esc)
- 1번 임무 단계별 튜토리얼 (튜토리얼 중에는 첫 웨이브 대기)

## 연출
WebAudio로 직접 합성한 효과음과 배경음악(외부 파일 없음). 배경음악은 화면 확대에 반응하는 3단 편곡입니다: 축소 시 저음, 기본 시점은 저음+중음, 확대 시 멜로디까지 전체 합주. 세 성부는 같은 곡을 함께 연주하고 음량만 바뀝니다. HUD 소리 버튼: 전체 → 음악 끔 → 전체 끔, 폭발 파편, 미사일 연기, 채굴 불꽃, 피격 섬광, 화면 흔들림.

## 일일 도전
날짜로 고정된 시드의 맵(4종 중 하나) + 변형 규칙 2개(적 속도, 채굴량, 태양광, 적 체력, 시작 자금, 웨이브 간격). 같은 날엔 모두 같은 맵이며, 오늘의 최고 웨이브가 기록됩니다. 무한 모드와 함께 5번 임무 완료 후 열립니다.

## 언어
한국어 / English. 브라우저 언어로 자동 선택되며, 임무 선택 화면 오른쪽 위 버튼으로 전환합니다.

## 앱으로 설치 (PWA)
오프라인 플레이 가능. 첫 접속 후 캐시되며, 업데이트는 다음 실행 때 반영됩니다.
- Android Chrome: 메뉴 → 홈 화면에 추가 / 앱 설치
- iOS Safari: 공유 → 홈 화면에 추가
- PC Chrome/Edge: 주소창 오른쪽 설치 아이콘

## 구조
빌드 도구 없이 바로 동작하는 정적 사이트입니다(Canvas 2D + 바닐라 JS, 외부 의존성 없음).

로컬 실행: `python -m http.server` 후 http://localhost:8000

## 테스트
```bash
pip install playwright && playwright install chromium
python tests/smoke.py              # 기능 스모크 테스트 (한국어·영어 각각)
python tests/balance.py 3          # 봇으로 임무별 승률 측정
python tests/smoke.py --url https://jflakeee.github.io/The_Space_Game/   # 배포본 대상
```
`tests/ci-example.yml`을 `.github/workflows/`에 복사하면 push마다 스모크 테스트가 실행됩니다.

## 릴리스 절차
1. `js/config.js`의 `APP_VERSION`과 `sw.js`의 `CACHE`를 같은 버전으로 올립니다(스모크 테스트가 일치 여부를 검사합니다).
2. `js/ui.js`의 "새 소식" 문구와 `CHANGELOG.md`를 갱신합니다.
3. `python tests/smoke.py` 통과 확인 후 push, `vX.Y.Z` 태그와 GitHub 릴리스를 만듭니다.
