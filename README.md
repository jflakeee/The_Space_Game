# Ore Belt

소행성 채굴 + 타워 디펜스 웹게임. 플래시 게임 The Space Game의 규칙에서 영감을 받은 클린룸 구현으로,
원작의 코드, 그래픽, 사운드는 사용하지 않았습니다.

플레이: https://jflakeee.github.io/The_Space_Game/

## 배포
```bash
git clone https://github.com/jflakeee/The_Space_Game.git
cp index.html .nojekyll README.md The_Space_Game/
cd The_Space_Game && git add . && git commit -m "Ore Belt" && git push
```
GitHub → Settings → Pages → Source: `main` / `/ (root)`

## 캠페인
맵 4종: 산개(scatter), 고리(ring, 기지를 둘러싼 소행성대), 군집(cluster, 먼 광맥 덩어리), 교차(lanes, X자 소행성 띠가 전력망을 가름). 무한 모드는 무작위.
임무 10개 + 무한 모드. 임무를 깨면 다음 임무가 열리고, 무한 모드는 5번 임무 완료 후 열립니다.
별점은 잃은 건물 수 기준(3개 이하 ★3, 10개 이하 ★2). 진행 상황은 브라우저에 저장됩니다.
건물은 임무 1–4에 걸쳐 단계적으로 해금됩니다.

## 편의 기능
- 도감: 건물·적 아이콘, 수치, 상대법 (메뉴/일시정지에서). 새 적이 처음 나오면 특징 안내
- 자동 저장(10초마다, 일시정지, 탭 전환, 페이지 닫을 때) → 임무 선택 화면에서 이어하기
- 일시정지 메뉴: 계속 / 다시 시작 / 임무 선택 (Space, Esc)
- 1번 임무 단계별 튜토리얼 (튜토리얼 중에는 첫 웨이브 대기)

## 연출
WebAudio로 직접 합성한 효과음과 배경음악(외부 파일 없음). 배경음은 적이 많을수록 밝아지고 아르페지오가 더해짐. HUD 소리 버튼: 전체 → 음악 끔 → 전체 끔, 폭발 파편, 미사일 연기, 채굴 불꽃, 피격 섬광, 화면 흔들림.

## 일일 도전
날짜로 고정된 시드의 맵(4종 중 하나) + 변형 규칙 2개(적 속도, 채굴량, 태양광, 적 체력, 시작 자금, 웨이브 간격). 같은 날엔 모두 같은 맵이며, 오늘의 최고 웨이브가 기록됩니다. 무한 모드와 함께 5번 임무 완료 후 열립니다.

## 언어
한국어 / English. 브라우저 언어로 자동 선택되며, 임무 선택 화면 오른쪽 위 버튼으로 전환합니다.

## 앱으로 설치 (PWA)
오프라인 플레이 가능. 첫 접속 후 캐시되며, 업데이트는 다음 실행 때 반영됩니다.
- Android Chrome: 메뉴 → 홈 화면에 추가 / 앱 설치
- iOS Safari: 공유 → 홈 화면에 추가
- PC Chrome/Edge: 주소창 오른쪽 설치 아이콘

## 구조
`index.html` 하나에 게임 전체 (Canvas 2D + 바닐라 JS, 의존성 없음). `sw.js`, `manifest.webmanifest`, 아이콘은 PWA용. 로컬: `python -m http.server`

| 건물 | 비용 | 역할 |
|---|---|---|
| 중계기 | 15 | 전력망 확장 (사거리 150, 소행성이 연결 차단) |
| 태양광 | 30 | 에너지 +1.6/s |
| 배터리 | 50 | 에너지 저장량 +100 |
| 채굴기 | 40 | 소행성 70 이내, 광석 2.2/s |
| 레이저 | 60 | 사거리 140, 22 dps, 에너지 소모 |
| 미사일 | 90 | 사거리 240, 범위 피해, 발사당 광석 2 |
| 감속탑 | 55 | 범위 110 내 적 이동·사격 50% 감속 (7번 임무 해금) |
| 수리소 | 70 | 범위 130 내 건물 수리 |

레이저는 Lv 2에서 **속사**(짧은 사거리, 높은 연속 피해)와 **저격**(긴 사거리, 체력 높은 적 우선 단발)으로 분기.
중계기는 최대 8개, 코어는 20개, 일반 건물은 2개까지 연결. 짓는 중인 건물과 중계기는 전액 환불, 나머지는 50%.
난이도 쉬움/보통/어려움(쉬움은 최대 ★2). 속도 버튼과 Space로 "정지" 가능하며 정지 중에도 건설·업그레이드 가능.

모든 건물(코어 포함)은 Lv 3까지 업그레이드 가능: 성능 +50%/레벨, 사거리·연결 거리·내구도 증가.

| 적 | 등장 | 특징 |
|---|---|---|
| 정찰기 / 약탈선 / 중형선 | 1 / 2 / 5웨이브~ | 기본 사격형 |
| 자폭선 | 4웨이브~ | 건물에 돌진해 범위 폭발 |
| 실드함 | 5웨이브~ | 주변 아군 받는 피해 50% 감소 |
| 모함 | 5웨이브마다 | 고체력, 8초마다 정찰기 2기 사출 |

밸런스는 자동 플레이 봇으로 임무별 승률을 측정해 조정했습니다(1–4 쉬움, 5–7 보통, 8–10 어려움).

밸런스 수치는 `index.html` 상단 `DEF`, `EN`, `MISSIONS` 객체에서 조정.
